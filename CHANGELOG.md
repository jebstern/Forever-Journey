# Changelog

## Unreleased

* Things you made: every item you craft, cook, smelt or conjure is counted per item
  ("Heavy Dynamite: 2,031"). The top items are on the Statistics page, the full list is in the
  Almanac, the item you made most is in Wrapped, and every 100, 500, 1,000 (and so on) items
  made becomes a chapter. Counts start when you install this version.

## 0.2.0

* New Settings page with every option in one place: banners, chat lines, World Map pins,
  window and banner size, the camping buff and erasing a character's data. Open it with the
  cog next to the close button, the sidebar, `/journey settings`, Shift-click on the minimap
  button, or Options > AddOns > Forever Journey.
* Choose which chapters get a banner: all, most (default) or only the major ones.
* `/journey help` lists every command, grouped. An unknown command says so before the list.
* Changing the window scale keeps the window where you dragged it.

## 0.1.1

* New command `/journey bannerscale <0.5-2>` to resize the banner independently of the window.
  The banner stays where you dragged it.

## 0.1.0

First public release.

* Journal window with Dashboard, Journey timeline, World, Statistics, Almanac, Next,
  Wrapped and Characters pages.
* 36 badges that become chapters on your timeline when earned.
* Banners for new chapters and personal bests, "Back in" memory banners and dungeon run recaps.
* World map tombstones where you died and footprints sized by time spent in each zone.
* Chat recaps when you level and a welcome-back line at login.
* Quests completed per zone on the World page when Questie is installed.
