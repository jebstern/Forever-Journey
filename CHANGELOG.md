# Changelog

## 0.1.0

First public release.

* Journal window with Dashboard, Journey timeline, World, Statistics, Almanac, Next,
  Wrapped and Characters pages.
* 36 badges that become chapters on your timeline when earned.
* Banners for new chapters and personal bests, "Back in" memory banners and dungeon run recaps.
* World map tombstones where you died and footprints sized by time spent in each zone.
* Chat recaps when you level and a welcome-back line at login.
* Quests completed per zone on the World page when Questie is installed.
